# Margrave

Open **Margrave** in the BB sidebar to browse installed skills. Search by name, ID, or description, or filter by source. Select **Refresh** after changing the Margrave store.

```sh
bb margrave list
bb margrave list --json
```

BB reads the Margrave store on its server. The `margrave` executable must be on the server's `PATH`.
